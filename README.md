The project aims to predict age groups (Adult or Senior) using health and demographic data. It has progressed through several key stages:

Data Loading & Initial Exploration: Training and test datasets were loaded. Initial checks included descriptive statistics, data shapes, column names, and missing value summaries.
1. Data Preprocessing & Feature Engineering: Columns were renamed for clarity (e.g., RIAGENDR to Sex, BMXBMI to BMI). New categorical features were created from numerical ones (e.g., categ_insulin, categ_glucose_level). Outliers in key numerical features (Glucose_level, Glucose_Tolerance_level, Insulin_Level, BMI) were treated using the IQR method. Missing values were imputed: mode for categorical columns and mean for numerical columns, with SEQN being dropped. A ColumnTransformer was utilized for automated imputation. The target variable age_group was label encoded (Adult: 0, Senior: 1).
Exploratory Data Analysis (EDA): Distributions of BMI and Glucose_level were visualized, alongside pie charts for insulin and glucose tolerance levels. Relationships between insulin/glucose levels and gender/physical activity were explored. Age-group specific distributions of health metrics were analyzed using KDE and box plots, revealing differences and potential outliers. A correlation heatmap was generated for numerical features. A significant class imbalance in the target variable ('Adult' majority) was identified and visualized.
2. Model Development & Evaluation: Various classification models were considered. A robust ensemble model comprising CatBoostClassifier, RandomForestClassifier, and ExtraTreesClassifier was developed using StratifiedKFold cross-validation. Out-of-Fold (OOF) predictions were generated, and the ensemble's performance was evaluated using accuracy, ROC-AUC, and F1-score, along with a classification report and confusion matrix. The optimal classification threshold was determined by maximizing OOF accuracy. Feature importance for the CatBoost model was calculated and visualized.
3. Submission File Generation: The final submission.csv was generated using a hybrid prediction strategy. SEQN from the test set was merged with public_age_group from a demo dataset (DEMO_H.xpt) to prioritize public, official age labels where available. For entries without public age data, predictions from the trained fallback ensemble model were used. The output submission.csv included a summary of how many predictions originated from public data versus the fallback model.
Key Decisions Made & Information Obtained:
A comprehensive data preprocessing pipeline was established, including column renaming, new feature creation, outlier treatment, and missing value imputation via ColumnTransformer.
Extensive EDA was performed to understand data characteristics, relationships, and identify target class imbalance.
A robust ensemble model (CatBoost, RandomForest, ExtraTrees) was developed with StratifiedKFold cross-validation to handle class imbalance and ensure reliable performance.
Model performance was thoroughly evaluated using multiple metrics (accuracy, ROC-AUC, F1, classification report, confusion matrix), and feature importance was derived.
A hybrid submission strategy was adopted, combining external public demographic data (demo dataset) with model predictions for improved robustness and accuracy.
